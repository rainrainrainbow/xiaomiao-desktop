针对“眼睛疼”做的 6 项关键改动

1背景降亮降饱和

去掉大面积高饱和黄 #F6D34A，改为低亮度深蓝灰 #1B2028（或暖纸色），屏幕整体发光量大幅下降。

2文字不再纯黑纯白

正文用柔和灰白 #C9CFD6、次要信息用 #808A97，避免纯黑/纯白造成的强对比刺激。

3选中态从棕块改柔底

原来选中就是整条高饱和棕色，改为低对比 #2F3B46 底色 + 细青绿描边，醒目但不刺眼。

4图标统一低饱和

六个图标不再红/紫/绿/橙各来一套，统一到青绿 + 暖橙两种低饱和点缀色，视觉更整。

5留白与行距加大

列表行距、图标间距重新排布，减少 160×128 小屏上的拥挤感，长时间浏览更轻松。

6两套主题可选

提供“暗夜 / 暖纸”两套护眼主题，弱光环境用暗夜、亮光环境用暖纸，设置里随时切换。

确认采用哪套主题（或提出调整意见）后，我再进入固件代码修改，并用 GitHub Actions 编译 + COM6 烧录 + 全测验证。
