## 二、逐模块差距清单

### 1. 系统升级 OTA
- 【已实现】检查更新、下载固件（流式写 flash）、校验（魔数+长度+esp_ota_end）、安装、进度、重启生效、重试
- 【部分】版本对比（仅显示远端 tag，不比较）、失败保留系统（factory 常驻但 ota_0 被原地覆盖）
- 【未实现】更新日志解析（release body）、**A/B 安全升级与回滚**、断电/中断保护
- **已有底座**：`launcher_b(ota_1)` 分区闲置可用；`esp_ota_mark_app_valid/invalid`、`CONFIG_BOOTLOADER_APP_ROLLBACK` 未启用

### 2. 系统设置
- 【已实现】Wi-Fi 扫描/连接/保存/断开、音量、亮度手动、睡眠+时长、NTP 自动时间、声音开关 UI、输出设备选择、蓝牙 A2DP Sink
- 【部分】信号显示（IP 仅日志不显示）、静音（driver 层未消费 `sound_on`）、唤醒（固定任意键）、时区（硬编码 CST-8）、恢复出厂（设置页与 Recovery 行为不一致）、应用管理（无详情/卸载入口）
- 【未实现】忘记网络、自动亮度、媒体/提示音音量、测试音/电平显示、定时关机、手动时间、时区选择、12/24 小时制、应用冻结解冻、清除范围提示、蓝牙主模式搜索配对、A2DP Source

### 3. 应用中心
- 【部分】SD 卡 `.app` 目录扫描、安装（纯文件复制）、已安装态显示、入口独立
- 【未实现】在线仓库、内置存储扫描、版本比较、来源标注、应用详情、升级、安装进度、checksum 校验、空间检查、签名校验接入
- **已有底座**：`app_manager.c` 有白名单/签名校验接口但未接入；`app.json` 已解析 version（仅用于签名）

### 4. 音乐播放
- 【已实现】播放/暂停/停止/切歌、独立高优先级播放任务、歌词（LRC 解析+4 行同步）、锁屏继续播放
- 【部分】播放模式（3 种，缺"顺序"）、队列（仅显示当前项）、后台播放（切界面即 stop）、歌词（无逐字、无歌词提示语义不准）
- 【未实现】进度拖动、队列增删调序清空、在线流媒体、离线缓存、音质切换、EQ（现为 `rand()` 假频谱）、高阶音效
- **已有底座**：`wav_decoder_seek()` 已实现 WAV/MP3 定位；`audio_backend_t` 可插拔；`drv_mic_lmd2718` 有 RMS 电平

### 5. 终端 Shell
- 【已实现】本地命令（help/ls/cat/echo/clear/sysinfo/mem/bat/sd/brightness/ver/py/reboot）、实时输出、清屏、滚动
- 【未实现】行编辑、命令历史+持久化、WebREPL、连接管理、远程权限控制、超时终止

### 6. 文件管理
- 【已实现】虚拟根（flash/sdcard）、目录导航、路径显示、文本查看、WAV 路由播放
- 【未实现】全部写操作（新建/重命名/删除/复制/剪切/移动/粘贴）、搜索、排序筛选、属性、回收站、空间提示
- **已有底座**：`ion_sdcard_get_free_space/total_space()` 已实现但零调用

### 7. LED 控制
- 【已实现】9 预设色+全局亮度、呼吸/流水/跑马/彩虹/闪烁效果、音乐律动 3 模式（自适应增益+包络跟随）、常驻后台任务、律动配置持久化、引用计数保活
- 【部分】逐颗设色（底层有 `set_pixel`，UI 无）、配置管理（仅律动配置）、律动灵敏度（全自动）
- 【未实现】速度/方向/循环次数可调、定时开关、方案保存加载、资源提示

### 8. 关于 About
- 【部分】系统/版本/构建、芯片、屏幕、DRAM/PSRAM/IRAM、uptime、电量电压、固件大小、分区表
- 【未实现】聚合页、摘要/详情分层、序列号/硬件版本、存储容量、网络 MAC/IPv4/IPv6/WiFi/蓝牙、CPU 占用/温度/充电、许可/EULA/支持反馈、快捷入口
- **已有底座**：`ion_sdcard_get_free_space()`、`app_sys_version()`、WiFi/蓝牙状态接口

### 9. 后台 Background
- 【部分】`bg_manager.c` 应用前后台状态表（8 槽 LRU，用于"最近任务"页）、LED/音乐/蓝牙/NTP 服务客观常驻、LED 引用计数保活
- 【未实现】任务类型列表、暂停/继续/取消/重试+进度、集中服务开关、自启动管理、资源监控、通知中心、休眠策略、冲突处理

### 横向能力
- 【已实现】多语言（中英双表，设置切换+持久化）
- 【部分】状态反馈（局部文本）、错误处理（局部+二次确认）、权限（安装白名单+破坏性二次确认）、后台共存（独立任务天然共存）
- 【未实现】统一状态组件、全局错误处理、**存储检查**（底层 API 零调用）、数据备份、终端/卸载/升级权限体系

## 三、实施路线（分批次）

> 原则：先共性底座，后模块功能；先 P0 后 P1/P2；每批次CI编译验证；全部完成后 COM6 烧录 + 全测。
> 受硬件限制项（空间音频/杜比/无损/在线流媒体/WebREPL）按"按硬件与授权能力支持"合理降级或明确标注。

### 批次 A — 共性底座（所有模块依赖）
- A1 扩展 `app_sys_api`：存储容量（内置+SD）、网络信息（MAC/IP）、设备信息、文件写操作封装
- A2 建立后台任务框架 `bg_tasks`：任务注册/进度/状态/暂停/继续/取消/重试
- A3 建立通知中心 `notifications`：事件发布/已读/清空
- A4 `lang.h/.c` 统一补充本轮全部新字符串（作为各模块契约，避免并发冲突）
- A5 CMakeLists 纳入新增源文件

### 批次 B — P0 基础能力（并行改造，文件边界隔离）
- B1 文件管理：读写操作 + 回收站 + 属性 + 排序筛选 + 空间提示
- B2 音乐：后台播放（切界面不停）+ 进度拖动（接 seek）+ 队列管理 + 顺序模式 + 歌词提示修正
- B3 Shell：命令历史（NVS 持久化）+ 行编辑
- B4 关于：聚合页 + 摘要/详情分层 + 存储/网络/硬件字段 + 快捷入口
- B5 OTA：A/B 安全升级 + 回滚 + 更新日志 + 版本对比
- B6 设置：静音生效 + IP 显示 + 忘记网络 + 时间(手动/时区/12-24) + 定时关机 + 恢复出厂统一与清除范围提示
- B7 应用中心：元数据/版本比较/来源 + 详情页 + 安装进度 + 校验 + 空间检查 + 签名校验接入
- B8 横向：存储检查落地 + 数据备份 + 敏感操作权限

### 批次 C — P1 核心体验
- C1 后台模块：任务列表页 + 服务开关 + 通知中心页 + 休眠策略（基于 A2/A3）
- C2 音乐：真 EQ 音效（流行/摇滚/古典/重低音，基于 audio backend DSP）+ 离线缓存
- C3 蓝牙：主模式搜索配对 + A2DP Source（音频发送）
- C4 LED：速度/方向/循环可调 + 律动灵敏度 + 定时开关 + 方案保存 + 资源提示
- C5 Shell：WebREPL（按网络栈能力）+ 连接管理 + 权限
- C6 音乐：在线流媒体（按网络与授权降级）

### 批次 D — P2 增强能力
- D1 自动亮度（需硬件传感器，无则标注不支持）
- D2 逐字歌词、高阶音效（按硬件/授权标注）
- D3 自启动管理、资源监控、冲突处理
- D4 许可/EULA/支持反馈页面、数据备份完善

### 批次 E — 集成验证
- E1 GitHub Actions 编译
- E2 下载固件烧录 COM6（0x120000 launcher）
- E3 全套 XTC 功能测试 + 新增功能回归测试
- E4 更新测试脚本覆盖新增功能

## 四、硬件/授权限制说明

以下需求依赖硬件、授权或内容源，将按"按硬件与授权能力支持"降级或明确标注：
- 空间音频 / 杜比全景声 / 无损音频：ESP32 + NS4168 + minimp3 不支持，标注为不支持
- 在线流媒体 / WebREPL：依赖网络栈稳定性（已知 WiFi 连接曾有问题），谨慎实现并降级
- 自动亮度 / 温度 / CPU 占用：无光线/温度传感器，RTOS 无现成 CPU 占用统计，标注不支持或近似
- 逐字歌词：需逐字时间轴 LRC（当前仅逐行），按需扩展解析
