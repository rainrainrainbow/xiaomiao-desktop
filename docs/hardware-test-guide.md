# XiaoMiao Desktop OS — 硬件测试指南

## 测试准备

### 硬件清单
- [ ] ESP32-WROVER-B 开发板 × 1
- [ ] ST7735 160×128 TFT 显示屏 × 1
- [ ] 6键手柄模块 × 1
- [ ] MicroSD 卡 (≤32GB, FAT32) × 1
- [ ] USB-UART 调试器 (如 CP2102/CH340) × 1
- [ ] 锂电池 (3.7V) × 1
- [ ] 蜂鸣器 × 1
- [ ] 杜邦线若干

### 接线表

| ESP32 引脚 | 连接目标 |
|-----------|---------|
| GPIO18 (SCLK) | ST7735 SCL |
| GPIO23 (MOSI) | ST7735 SDA |
| GPIO19 (MISO) | ST7735 — (未用) |
| GPIO5 (CS) | ST7735 CS |
| GPIO4 (DC) | ST7735 DC |
| GPIO22 (SD_CS) | MicroSD CS |
| GPIO2 (UP) | 按键 UP |
| GPIO13 (DOWN) | 按键 DOWN |
| GPIO27 (LEFT) | 按键 LEFT |
| GPIO35 (RIGHT) | 按键 RIGHT |
| GPIO34 (A) | 按键 A (注意: 仅输入) |
| GPIO12 (B) | 按键 B (注意: 启动时高电平=禁止烧录) |
| GPIO0 | 背光 PWM (或通过电阻接LED) |
| GPIO34 (ADC1_CH6) | 电池分压电路 |

### 固件烧录

```bash
# 从 GitHub Releases 下载最新 merged.bin
# 或本地构建
cd xiaomiao-desktop
idf.py build

# 烧录
esptool.py --chip esp32 -p /dev/ttyUSB0 -b 460800 \
  write_flash 0x0 xiaomiao-desktop-merged.bin

# 查看串口日志
idf.py -p /dev/ttyUSB0 monitor
```

## 故障排除

### 屏幕不亮
1. 检查 ST7735 接线是否正确
2. 检查背光 GPIO0 是否有 PWM 信号
3. 串口查看是否有 `LCD initialized` 日志

### 按键无响应
1. 串口输入 `keypad_init` 后看是否有日志
2. 用万用表测量按键引脚电平
3. 检查 BUTTON_ACTIVE_LEVEL 配置（默认低电平有效）

### SD 卡不识别
1. 确认 SD 卡格式为 FAT32
2. 检查 SPI 接线（CS=GPIO22）
3. 串口查看 `SD card mount failed` 原因

### 烧录失败
1. 按住 BOOT 键再上电
2. 检查 GPIO12 是否被拉高（B键在启动时不能按下）
3. 降低波特率: `esptool.py -b 115200 ...`
